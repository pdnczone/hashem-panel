# نودها: یک پنل برای همه سرورها

یک پنل **مرکز** است و بقیه سرورها به‌صورت **نود** به آن وصل می‌شوند.
طراحی در [PLAN_NODES.md](PLAN_NODES.md) است.

## افزودن سرور

در پنل مرکز، صفحه **نودها** را باز کنید و یکی را انتخاب کنید:

- **افزودن سرور**: پنل دو خط می‌دهد. یکی را با root روی سرور جدید اجرا کنید:
  اگر هاشم نصب است `hashem node-join ...`، و اگر نیست خط `bash <(curl ...) node-join ...`
  (اول هاشم را نصب می‌کند، بعد وصل می‌شود). کد یک بار و تا ۳۰ دقیقه کار می‌کند.
- **افزودن با SSH**: IP سرور، پورت SSH، کاربر و رمز (یا کلید خصوصی) را بدهید. پنل
  کلید میزبان SSH سرور را برای تأیید نشان می‌دهد، بعد یک بار وارد می‌شود، هاشم را نصب
  یا به‌روز می‌کند و سرور را وصل می‌کند. رمز یا کلید ذخیره نمی‌شود.

اولین سروری که اضافه کنید این پنل را مرکز می‌کند. به تانل‌هایی که الان برقرارند در
هیچ سمتی دست زده نمی‌شود.

روی هر سرور، `hashem node status` نقش آن را نشان می‌دهد و `hashem node leave` آن را
دوباره مستقل می‌کند.

## چطور کار می‌کند

- نود به پورت پنل مرکز وصل می‌شود (آدرسِ داخل کد؛ پیش‌فرض IP عمومی و پورت پنل مرکز).
  روی نود پورت تازه‌ای باز نمی‌شود.
- داخل این اتصال، دو طرف TLS 1.3 با کلیدِ ثبت‌شده‌ی همدیگر اجرا می‌کنند: کلید مرکز در
  کد است و مرکز کلید نود را هنگام اتصال ثبت می‌کند. گواهی یا دامنه لازم نیست و پنل‌هایی
  که HTTP ساده دارند هم همین‌طور محافظت می‌شوند.
- فقط مرکز درخواست می‌دهد؛ نود از هیچ‌کس جز مرکزِ ثبت‌شده‌اش فرمان نمی‌گیرد. در این
  کانال shell یا دسترسی به فایل نیست.
- اگر مرکز یا مسیر قطع باشد، همه تانل‌ها کار می‌کنند و نود خودش دوباره وصل می‌شود
  (هر چند ثانیه، تا حداکثر دقیقه‌ای یک بار).
- هر نود پنل محلی کامل خودش را نگه می‌دارد.

## حذف یا خروج

- **حذف** در مرکز: به نود خبر داده می‌شود و دوباره پنل مستقل می‌شود. تانل‌هایش کار می‌کنند.
- **خروج از مرکز** روی نود (یا `hashem node leave`): مرکز آن را از فهرستش برمی‌دارد.
- مرکزی که نودی ندارد می‌تواند **از حالت مرکز خارج شود**.
