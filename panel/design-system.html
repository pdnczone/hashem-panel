Enterprise Network Dashboard — Design System

Phase 1 · Option C · additive .ent-* components · existing styles untouched

0 · Rules (2026-10 review against Apple's HIG)

These hold for every screen; panel/ui_a11y_test.go and panel/i18n_fa_test.go enforce the ones a test can check.

  • Color: only tokens from tokens.css; one color, one meaning. Accent = primary action and current selection. Status colors = status only. Tints are color-mix(var(--token) N%, transparent); white text sits on --ac-fill or a --*-fill. Text is at least 4.5:1 in both themes.
  • Type: nothing below 12px; weights 400–700; numbers use tabular figures; Persian uses Vazirmatn one step larger.
  • Hierarchy: one primary button per card; button labels in Title Case, descriptions in sentence case; one action keeps one name from button to dialog to confirmation.
  • Depth and motion: two shadow levels (--lift-sm, --lift), no glows, no hover lifts; motion is brief and off under reduced motion.
  • Icons: the SVG sprite in index.html (#i-*); no emoji.
  • Layout: spacing on the 4/8 grid; utilities (u-*) instead of inline style; no horizontal scroll at 375px; card headers wrap.
  • States: before setup nothing is red; empty states say what to do next; a result that never answered is not a recommendation.
  • Language: UI source is English; Persian lives in i18n-fa.js; in RTL each text run takes its own direction and values sit in <bdi>.
  • Signature: the topbar link strip (this server ⇄ the other side · engine · latency, one live dot) is the one distinctive element; everything around it stays quiet.
