Carriers

              
How each tunnel travels. When a network starts blocking or slowing one, swap it: both servers switch, and if the new carrier does not connect they go back on their own.

            

          

          

        

        
        

          

            

              
GRE wrap

              
How the main tunnel's GRE packets travel between the two servers. Direct GRE is the fastest. WSS wraps them in TLS on a web port, for networks that block or slow down GRE (protocol 47). 6to4 and 4in6 carry them over IPv6.

    FRP Transport
    
            —
          
    
          
    The FRP options of this tunnel. Encryption, compression and multiplexing only cost CPU and speed for VLESS, Reality and Trojan, whose traffic is already encrypted: leave them off unless a service needs them.
    
          
    
            FRP transport options
            
    
              
              
              
              
    
                
                
                
    Sends each user's real IP to the service on this server, so Xray logs, limits and IP checks see real users instead of 127.0.0.1. Turn on Proxy Protocol (acceptProxyProtocol) in the Xray inbound first: without it every connection fails.
    
                
    
              
    
              
    
                
                
    MB/s
    
                
    A cap on each forwarded port, for all its users together (megabytes per second). 0 means no limit.

      New Pool
      
    
      
    
      
      
      
        
      
          
      Several at once: 443, 8443 or 2000-2005 (one pool each).
      
        
      
          
      
      
      
      
      
      
      
        
        
      
      
      
      
      
        
      
      
      
        
      
          
      
        
      
      
      
      
      The service check opens a connection through each foreign server to the service behind it (for example xray on 443). A server whose tunnel is up but whose service refuses the connection is taken out. TCP pools only.
      
      
      
        Foreign servers in this pool
        
      
        
      Tunnels whose ports include this port join by themselves. Each one's relay restarts once (a few seconds) to move behind the pool. Standby servers get traffic only when no other server can take it; a server at its connection limit takes no new connections until it drops below 90% of it.
